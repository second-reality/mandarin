Learn Mandarin
##############

Based on Let's learn Mandarin books from Taiwan.
Write using xournalpp (install latest from
https://github.com/xournalpp/xournalpp)

Import flashcards per lesson in anki, using anki desktop with quizlet addon.
Addon (supports audio import): https://ankiweb.net/shared/info/1362209126

Translate teacher book with:
- split in N pdf to keep size < 10MB
qpdf --empty --pages teacher.pdf 101-144 -- 3.pdf
- use google translate on each
- assemble: pdftk *.pdf output output.pdf

Book 1 - 3:
https://taiwancenter.taiwan-world.net/material/basic
